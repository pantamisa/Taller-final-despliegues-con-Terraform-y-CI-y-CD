# Taller-final-despliegues-con-Terraform-y-CI-y-CD

Comprender los conceptos fundamentales de DevOps mediante la investigación de 
términos técnicos y el desarrollo de ejercicios prácticos sencillos que permitan 
identificar cómo se automatiza la construcción, prueba, implementación, 
administración y protección de una aplicación de software.
